Modified:

- `Views/ReactView.tsx` — passes `this.app` as a prop now instead of via context
- `src/services/bookmarks.ts` — fixed `getBookmarks()`'s declared return type (`TAbstractFile[]` → `TFile[]`), which was blocking the new hook and was stale from §6
- `REFACTOR docs/REFACTOR-DECISIONS.md` / `REFACTOR-IMPLEMENTATION-CHECKLIST.md`
- The `Icon` component doesn't just isolate `dangerouslySetInnerHTML` anymore, it kills it outright — `getIcon()` hands back a real `SVGElement`, so `Icon` appends that DOM node directly via a ref instead of serializing it to a string first.

Incidental hardening, surfaced by relocating logic rather than requested separately:
- `useClock` now depends on `timeFormat` alone instead of the whole settings object — the original tore down and rebuilt the interval on *any* settings change, not just a time-format change. Displayed output is identical; only teardown/rebuild frequency changes.
- `useQuote` adds a `cancelled` guard around the async fetch, so a slower stale request can't clobber a newer one if the quote source changes again before the first resolves.
- `BackgroundSurface` now omits the `style` attribute entirely when there's no background, instead of writing a literal `url('null')` into the DOM for transparent themes — no visible effect (those themes already hide any background via CSS classes), just stops emitting invalid CSS.
- `useRecentFiles` and `useBookmarks` deliberately match, rather than improve, their original memoization: `useRecentFiles`'s old `useMemo` was keyed on a fresh array literal every call, so it never actually memoized anything — the hook now just recomputes plainly, same effective behavior, without a fake memo. `useBookmarks`'s original memo genuinely worked (keyed on stable references) and is preserved as-is.

Deleted:
- `React/Context/ObsidianAppContext.ts`
