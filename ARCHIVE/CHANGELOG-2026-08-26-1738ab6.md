## Notes

This commit focuses on modernizing the toolchain and build surfaces for this project. `npm` was dropped in favor of `pnpm`, `.eslintrc` was migrated to a flat config and `eslint` brought up to date, and a host of decisions were made with regard to what node versions were supported, build targets, and more.

**§1 — Toolchain And Build**

- **Dependencies**: `engines.node` set to `>=24`; TypeScript held at 5.9.3 rather than the newly-GA'd TS7, since `typescript-eslint`/`eslint-plugin-obsidianmd` have a hard `<6.1.0` peer ceiling not expected to lift until TS 7.1; `@typescript/native-preview` (`tsgo`) added as a second, non-gating `typecheck:fast` script instead. `esbuild` bumped 0.19.8 → 0.28.2, forcing a coordinated `esbuild-sass-plugin` bump that added a native `sass-embedded` dependency. The `obsidian` package was pinned to `^1.13.1` for the first time — it had been sitting on the literal unpinned string `"latest"`. React/typings held at 18.x on purpose (typings-only pass, not a React major bump).
- **ESLint**: flat config's imported packages (`eslint`, `@stylistic/eslint-plugin`, `eslint-plugin-obsidianmd`, plus undocumented peer deps `typescript-eslint`, `@eslint/js`, `@eslint/json`) were never actually installed before this pass, so `lint` could not have run previously. `.tsx` was missing from both the lint glob and `tsconfig.json`'s `include` — every React component had been silently unchecked. First real lint run surfaced 193 stylistic fixes (safe) plus 342 real errors / 53 warnings (mostly private-API access, deferred to §6/§8). **Lesson learned the hard way**: unscoped `eslint --fix` also applies "suggestion"-level autofixes for every rule, not just the stylistic ones requested — it silently converted 9 `any` → `unknown` and stripped a load-bearing `as any` cast, both caught only by re-running the full pipeline afterward and reverted by hand. Scope future stylistic-only fixes with `--fix-type layout`.
- **`electron` removed as a stopgap**: pulled forward from its original §4 slot after `npm audit` flagged 2 high-severity CVEs on the pinned version. `fs`/`path`/`electron` imports dropped from `main.ts` and `Settings.ts`; the three features they backed (OS-folder sync, "Browse", "Add local image") were disabled, not replaced, at the time — though the folder-sync feature's real vault-relative replacement (`src/services/backgrounds.ts`) was in fact built later in this same pass, pulled forward from §4 rather than left broken.
- **Package manager**: pnpm adopted for real (previously flagged, never wired up). `package-lock.json` dropped, `pnpm@11.24.0` pinned via `packageManager`. `esbuild` and `@parcel/watcher`'s build scripts explicitly allowed via the new `pnpm-workspace.yaml` (pnpm 11 moved this config out of `package.json` entirely, silently).
- **Build target**: three previously-disagreeing numbers (`tsconfig` ES6, esbuild es2018, and an actual-checked lib silently leaking to ES2020 via `@types/node`) unified to one honest **ES2020** everywhere, chosen after actually researching Obsidian's runtime (desktop Electron version lags the app's own updater; mobile is a WebView with documented fragmentation, e.g. iOS 16.4+ needed for regex lookbehind).
- **tsconfig cleanup**: `baseUrl` removed (forced by `tsgo`, which hard-errors on it) and replaced with an equivalent `paths` map; `moduleResolution` moved to `bundler`; `lib` collapsed from a redundant `ES5/ES6/ES7` stack to `["DOM","ES2020"]`. The actual mixed-alias import style this was meant to eventually clean up is untouched — deliberately deferred to §8.
- **Strictness turned on for real**: `strictPropertyInitialization` and `strictFunctionTypes`, surfaced only by `tsgo` disagreeing with `tsc` on defaults. Fixed all 10 resulting errors immediately rather than deferring, including a real latent runtime bug in `App.tsx`'s bookmarks render path (a `TFile`-only callback silently mishandling bookmarked folders) and confirming §5's already-suspected enum-narrowed `Setting` callback bug was real (plus a fifth, differently-broken callback found in the same sweep).
- **First-ever successful build**: `pnpm run build` completed successfully in this branch's history for the first time this pass, unmasking two previously-hidden, pre-existing bugs — the `assert`-syntax JSON import in the build script, and a stale Sass `@use` path in `styles.scss` pointing at a directory that didn't exist. Both fixed.
- **Deferred/relocated**: "Choose one import strategy" and the `noUnusedLocals`/`noUnusedParameters` evaluation both moved to §8, since they're really file-structure concerns, not toolchain-version ones.
